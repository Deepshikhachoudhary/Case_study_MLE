# E-Commerce Customer Segmentation

This project groups e-commerce customers based on their purchasing behavior using machine learning.

## Features
- Analyzes customer Recency, Frequency, and Monetary value (RFM).
- Uses K-Means and DBSCAN clustering.
- Visualizes customer groups using PCA and t-SNE.
- Creates customer personas and suggests marketing strategies.

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

## Objective
To understand customer behavior, identify valuable customers, and help businesses improve their marketing strategies.

## How to Run
1. Download or clone this repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run all cells.

## Conclusion
K-Means provided clearer customer segments for this dataset, helping businesses understand different customer groups and plan targeted marketing campaigns.
